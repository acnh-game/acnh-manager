# ACNH-Manager

Switch 上的自制应用(NRO):**通用游戏安装器 + 动森 Game Agent 管理器**。
安装包由用户自己提供——从 SD 卡选本机文件、给一个下载网址,或用手机/电脑浏览器直接上传;
支持 NSP / NSZ / XCI / XCZ,可装游戏本体、更新包与追加内容,装完还能一键管理动森 Game Agent
(当前实现为 `acnh-agent`)。

本工具**不提供、也不托管任何游戏内容**。

## 当前支持范围

- **安装器**:NSP / NSZ / XCI / XCZ;游戏本体、更新包、追加内容。一个文件里带多份 meta 的整合包
  会逐份安装。`.msp`(mod 包)明确不支持,请用支持它的工具安装。
- **动森 Game Agent**(当前实现为 `acnh-agent`):**仅支持 Animal Crossing: New Horizons 3.0.3**
  (title id `01006F8002326000`,标题版本 `2228224`)。其他游戏的安装包照样能装,只是不会涉及
  动森 Game Agent;动森其他版本的包会明确提示"动森 Game Agent 不支持此版本",不会给出误导性的提示。
- 游戏内容由用户自备:本应用不下载、不内置、不分发任何游戏或更新文件。
- 名字里的 `nh` = Nintendo Homebrew,是本项目线的家族前缀;覆盖全部动森作品,但动森 Game Agent 当前只有
  上面这一个受支持的构建。
- 界面支持简体中文与 English。
- 首次启动没有已保存设置时按主机系统语言选择界面:中文系统使用简体中文,其他语言使用 English;
  系统语言读取失败时也使用 English。用户在详情页切换后会持久化，不再跟随系统变化。
- 页脚构建信息按构建类型显示：Switch 的开发、脏工作树和手工构建保留完整构建串；干净正式发布显示
  `版本 2.0.0` / `version 2.0.0`。浏览器开发版为窄屏显示紧凑的 `src` 串，点按复制完整值。
  完整构建串仍写入 `log.txt`。

## 它做什么

### 装游戏:三种来源

- **本机文件**:从 SD 卡里选一个包,直接读、直接装;文件列表右侧写明"安装包 / 忽略"和文件大小。
- **下载安装**:在主机软键盘里输入地址,或直接用手机/电脑打开主机页面粘贴地址,由主机边下边装
  (要求服务器支持 HTTP Range,否则直接拒绝)。
- **上传安装**:主机显示局域网地址与二维码,手机或电脑打开页面选择文件上传,**全程不需要互联网**。

三条来源共用同一条安装流水线,都支持断点续传。

### 安装页

- **选择目标存储**:页眉的 `安装到: microSD / 系统` 两组控件可触摸、也可用 `L` / `R` 切换;
  选择会记住,下次进来仍是同一条。装不下时由建占位那一步报出系统给出的原因,不进入传输。
- **断点续传**:中断后任务文件与占位都保留;回到安装页按提示继续。网页上传需要重新选同一个文件,
  已完成的其它内容不会重下;NSZ / XCZ 的单个内容会整段重来(zstd 流无法从中间进入)。
  重启主机会清空系统占位,那之后同一任务从头开始。
- **跳过与防降级**:同版本已装、或机器上已有更高版本时直接跳过;默认不允许降级。
- **装前确认**:显示游戏名、版本、类型、大小、目标存储,封面取自安装包自身(不依赖机器上是否
  已装该游戏);游戏名按应用语言优先,主机语言不同时另起一行。
- **进度与时间**:已传 / 总量、当前内容、速度与剩余时间。速度取最近 5 秒的滑动窗口:开头的
  建占位、读文件头不会拖住后面的平均速度,传输停住时速度和剩余时间一起消失,不会继续报一个
  不再成立的数。
- **手机页面是主机的镜像**:同一份进度、同一张封面、同样的「开始安装 / 返回」、存储切换与页脚
  构建戳;开始与返回都通过带 `runId` 的接口在主机上执行同一动作。页面不提供取消,与主机一致。

### 管理动森 Game Agent

1. 识别控制台上实际装的是哪个构建:读应用版本(`ns`)与更新包的 Program 内容 id(`ncm`),再用
   `(title id, 版本号, 内容 id)` 在发布清单 `games[]` 中选中对应条目;游戏恰好在运行时还会用
   `dmnt:cht` 读 `main` 的 ModuleId 做字节级复核。
2. 校验并写入 `atmosphere/contents/01006F8002326000/exefs/{subsdk9, main.npdm, acnh-agent.version}`,
   记录安装状态;支持一键卸载回滚。
3. **自动跟随安装**:装完本体或更新、且最终版本受支持(3.0.3)时,自动把动森 Game Agent 一并装上;
   追加内容、数据补丁与不受支持的版本都不触发,已装则跳过。
4. **离线可用**:发布清单与 payload 内嵌在 NRO 里;启动时静默检查一次更新,首页也可把焦点移到「检查更新」后按 `A` 手动检查。
   远端版本更高时直接给出"更新到 X";下载由清单签名的公钥背书(App 内嵌公钥,ECDSA P-256),
   每个文件都按清单里的 size + sha256 校验后才落盘。检查失败静默退回内置版本。
5. 内置**聊天码说明页**(`－` 或页面切换直达),讲清聊天码怎么写,并带上《森友物码册》小程序码。

### 从桌面直接启动

首页最下方的「安装桌面快捷方式」会在 HOME 菜单创建一个启动入口,固定指向
`sdmc:/switch/ACNH-Manager/ACNH-Manager.nro`(FAT32 大小写不敏感,卡上发布文件名仍为
`acnh-manager.nro`);安装目标固定为 microSD。已安装时同一按钮改为
「删除桌面快捷方式」。它使用应用内预生成的 forwarder NSP,安装过程不需要密钥、网络或额外工具。
生成该 NSP 时,`tools/build-forwarder.py` 会在固定 devkitPro 容器中从 hbl 源码现场编译 loader。

判据链、实测证据与 SD 布局见 `docs/architecture.md`(改行为前必读)。

## 安装与使用

1. **官方 Homebrew App Store**:在相册里打开 Sphaira 等商店客户端,搜索 `ACNH-Manager`。
   商店收录版本可能暂时落后于本文描述的 2.0.0;2.0.0 升级 PR 已按计划暂缓,未提交;
2. **直接下载发布 NRO**:发布版本入库并推送后,地址为
   `https://gitee.com/acnh-game/acnh-manager/raw/main/packaging/nro/acnh-manager-<版本>.nro`;
   放进 `switch/ACNH-Manager/`,从相册打开。源码用户也可先运行 `./tools/build.sh`;
3. 首页按 `＋` 进入「游戏安装/更新」,选一种来源;
4. 手机上传:进入「上传安装」后扫码打开页面、选择文件。**请让页面保持在前台**——锁屏或切到后台
   会被浏览器暂停,重新打开页面重选同一个文件即可从断点继续。

项目源码在 Gitee:`https://gitee.com/acnh-game/acnh-manager`。

## 已知边界(明确不做)

- 不卸载游戏或更新包,不修改存档;不管理 cheat 文件,只检测冲突并提示路径。
- 安装动森 Game Agent 时,若目标目录已有非本应用写入的同名 `subsdk9` / `main.npdm`,会**直接覆盖**,
  不弹覆盖确认,也不保留用户可见的旧文件备份。
- 一次只装一个文件;主机与页面都不提供主动取消。异常中断可续传,但收尾阶段不可取消。
- **不读取 `prod.keys` / `title.keys`**:需要密钥的转换(转公共票、转标准 crypto、降低 master key)
  不做;包内票据原样导入,交给系统判断。
- 校验默认跟随参考实现:跳过 NCA 全文件哈希与 NCA 头 RSA 固定密钥校验;XCI 的 distribution 位会
  改成 system。改装内容能否启动取决于用户自己的 Atmosphere / sigpatches 配置。
- 不支持 `.msp`;不提供 HTTP 认证(局域网地址本身就是入口凭证)。

## 构建与部署

```bash
# 构建(固定镜像 devkitpro/devkita64:20260219;Docker 需 escalation)
./tools/build.sh

# 开发期部署到 Switch(经 sys-agent 的 FTP,端口 6001)
python3 tools/deploy-nro.py
```

产物为 `acnh-manager.nro`;正式发布经官方 Homebrew App Store,打包、上架与托管地址见
`docs/release-process.md`(发行流程)与 `docs/store-listing.md`(条目元数据)。
